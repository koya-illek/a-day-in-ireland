# A Day in Ireland

A living, near-real-time portrait of weather and sea conditions across Ireland.

## Data

- Met Éireann observations and warnings, licensed under CC BY 4.0.
- Marine Institute Irish Weather Buoy Network observations, licensed under CC BY 4.0.
- Solar position and daylight state are calculated locally.

Observed data is indicative. Missing or stale values are not represented as zero.

## Development

```bash
npm install
npm run dev
npm test
npm run test:e2e
npm run build
```
